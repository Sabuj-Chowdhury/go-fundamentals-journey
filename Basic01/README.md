# Basic01 - Functions, Variables & String Formatting

This program demonstrates the fundamentals of Go programming, including:

- **Functions**: Defining and calling a custom function (`coffeeOrder`)
- **Variables**: Declaring variables with inferred types using `:=`
- **Parameters & Return Types**: Passing arguments (`string`, `int`) and returning a `string`
- **String Formatting**: Using `fmt.Sprintf` to format a string and `fmt.Println` to print output

## How It Works

The `coffeeOrder` function takes three parameters — a name, a coffee type, and a price — and returns a formatted order summary string.

### Output

```
Order for Sabuj: Latte coffee costs 450 taka
```

## How to Run

```bash
go run main.go
```
